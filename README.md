# 私人伤感情歌炫酷播放器
纯前端音乐播放器，本地导入MP3伤感情歌，支持音频频谱可视化、旋转黑胶唱片、自动切歌、进度拖拽，支持GitHub Pages在线打开。

## 功能
1. 暗黑伤感粉紫渐变炫酷UI
2. 实时音频波形可视化背景
3. 黑胶唱片旋转动画
4. 批量上传本地伤感情歌mp3
5. 上一首/下一首/自动循环
6. 进度条拖拽跳转播放
7. 自动记录歌单

## 使用教程
1. 克隆/下载本项目到本地
2. 打开index.html即可离线播放
3. 点击上传按钮添加你收藏的伤感情歌
4. 部署GitHub Pages：仓库设置开启Pages，选择main分支

## 技术栈
HTML5 + CSS3 + JavaScript
Web Audio API 音频频谱可视化
原生Audio标签播放音乐
